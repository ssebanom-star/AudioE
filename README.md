# vocal_aid

UTAU 식 노트 매핑 기반 보컬 음정보정 엔진. 소스 음성을 멜로디(MIDI/MusicXML)의
각 음표에 맞춰 잘라 붙이고, 음정을 음표 주파수로 평탄화한다.

**이 도구가 아닌 것:** 가창 합성(SVS)도 아니고, 음색 변환(SVC)도 아니다. 신경망과
학습 과정이 전혀 없다. WORLD vocoder 기반 F0 치환 + 프레임 타임스트레치만 수행하는
순수 DSP 도구다.

## 왜 WORLD인가

WORLD는 음성을 세 개의 독립적인 레이어로 분해한다 -- F0(음정), SP(스펙트럼
엔벨로프 = 음색/포먼트), AP(비주기성 = 숨소리/거칠기). 레이어가 독립적이기 때문에
**F0만 음표 주파수로 치환하고 SP/AP는 그대로 보존**하면, 음정이 얼마나 크게
움직이든 화자의 음색과 포먼트가 유지된다.

PSOLA 계열이나 단순 리샘플링 기반 피치 시프터는 피치를 옮길 때 스펙트럼
엔벨로프(포먼트)도 함께 이동시킨다 -- 이게 음높이를 올리면 "다람쥐" 소리가 나고
내리면 "거인" 소리가 나는 원인이다. WORLD의 분해/재합성 구조는 이 문제 자체를
원천적으로 차단한다.

## 사용법

```bash
python -m vocal_aid --source in.wav --melody song.mid --mode a --flatten 0.9 --out out.wav
```

### 주요 옵션

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--source` | 소스 보컬 WAV (필수) | - |
| `--melody` | 멜로디 파일, `.mid`/`.midi` 또는 `.xml`/`.musicxml`/`.mxl` (필수) | - |
| `--mode` | `a` (자동 음절 분할) 또는 `b` (단일 샘플 반복) | `b` |
| `--flatten` | `0.0`~`1.0`. 1.0=완전 고정, 낮을수록 원본 피치 흔들림 잔존 | `1.0` |
| `--portamento-ms` | 음표 진입 시 포르타멘토 글라이드 길이(ms) | `30.0` |
| `--vibrato-rate` | 비브라토 속도(Hz), 0=비활성 | `0.0` |
| `--vibrato-depth` | 비브라토 깊이(semitone), 0=비활성 | `0.0` |
| `--preserve-attack` | 타임스트레치 시 고정할 어택/릴리즈 구간(ms) | `0.0` |
| `--frame-period-ms` | WORLD 분석 프레임 주기(ms) | `5.0` |
| `--out` | 출력 WAV 경로 (필수) | - |

## 파이프라인

```
소스 wav → WORLD 분해(f0, sp, ap)
→ [매핑 전략 분기: 모드 A | 모드 B] → 음표별 프레임 세그먼트
→ 세그먼트별: 프레임 타임스트레치(음표 길이 맞춤) + F0 평탄화(음표 주파수)
→ WORLD 재합성 → 음표 연결 → 출력 wav
```

매핑 전략 분기 이후의 타임스트레치/평탄화/재합성 단계는 모드 A와 B가 완전히
공유한다 (`vocal_aid/pipeline.py`).

## 매핑 모드

### 모드 B -- 단일 샘플 반복 (`--mode b`, 기본값)

소스에서 가장 긴 유성(voiced, f0>0) 구간 하나를 찾아 모든 음표에 그대로
재사용한다. 가사/발성 변화는 무시한다. 경계 검출이 전혀 없으므로 **가장
안정적**인 모드다.

### 모드 A -- 자동 음절 분할 (`--mode a`)

소스를 에너지(WORLD SP 프레임 평균) + 보이싱(WORLD f0>0)을 결합한 임계값으로
발성 구간을 나누고, N번째 발성을 N번째 음표(쉼표 제외)에 1:1 매핑한다.

- 발성 수 < 음표 수: **마지막으로 검출된 발성을 남은 음표에 반복**해서 채운다.
- 발성 수 > 음표 수: **초과한 발성은 버린다(절단)**.
- 발성이 하나도 검출되지 않으면 소스 전체를 모든 음표에 재사용한다(모드 B로
  자동 폴백).

**한계:** 이 경계 검출은 학습된 분할기가 아니라 단순 에너지/보이싱 휴리스틱이다.
숨소리로 시작하는 발성, 치찰음, 음절 간 포르타멘토 글라이드, 잡음이 섞인
녹음에서는 경계를 잘못 잡을 수 있다. 가사나 음소를 인식하지 않으며, "여기서
무언가 발성됐다"는 신호만 찾는다.

## F0 평탄화

계단형 완전 평탄화는 로봇처럼 들리므로, 음표마다 다음 레이어를 순서대로
적용한다:

1. **진입 포르타멘토** (`--portamento-ms`, 기본 30ms) -- 이전 음표의 종료
   주파수(또는 세그먼트 자체의 시작 피치)에서 목표 음표 주파수까지 선형 글라이드.
2. **서스테인** -- 나머지 구간은 음표 주파수로 평탄.
3. **`--flatten`** (`0.0`~`1.0`) -- 위에서 만든 평탄화 곡선과 원본 F0를 블렌드.
   `1.0`=완전히 음표에 고정, 낮을수록 원본 피치 흔들림이 일부 남는다.
4. **비브라토** (옵션, `--vibrato-rate`/`--vibrato-depth`) -- 서스테인 구간에만
   사인파 변조를 추가한다.

**무성음 구간(f0=0)은 평탄화 대상에서 제외**하고 항상 0으로 유지한다 (없는
피치를 만들어내지 않는다).

## 타임스트레치

별도의 타임스트레치 라이브러리를 쓰지 않는다. WORLD 프레임(f0/sp/ap)을 프레임
축에서 선형 보간/리샘플링해 음표 길이에 맞춘다. `--preserve-attack`을 주면
세그먼트 양 끝의 어택/릴리즈 구간은 1:1로 유지(고정)하고, 중앙 서스테인 구간만
신축한다 -- 모음이 과도하게 늘어지는 것을 완화하기 위한 옵션이다.

**한계:** 이 보간은 프레임 단위 선형 보간일 뿐이며, 위상 정합(phase-aware)
타임스트레치가 아니다. 음표가 소스 발성보다 훨씬 길어지면 모음이 부자연스럽게
늘어질 수 있다 (`--preserve-attack`으로 일부 완화 가능).

## 음색 보존의 한계

WORLD는 SP(스펙트럼 엔벨로프)를 건드리지 않으므로 작은 음정 이동에서는 음색이
거의 그대로 유지된다. 그러나 **음정 이동이 매우 클 경우(예: 1옥타브 이상)** SP를
보정하지 않으므로 포먼트가 원래 음높이에 고정된 채로 남아 다소 부자연스럽게
들릴 수 있다 (예: 낮은 음에 어울리는 포먼트로 아주 높은 음을 내는 부조화).
이는 SVS/SVC가 아닌 순수 F0 치환 엔진의 본질적인 한계다.

## 범위 밖

가창 합성, 화자 학습, 실시간 처리는 이 프로젝트의 목표가 아니며 구현되어 있지
않다.
